# ペナントレース シミュレーター 本編(AIの検証用)

架空のプロ野球リーグで遊ぶブラウザゲーム「ペナントレース シミュレーター」の**本編**です。AI に遊んでもらったり、動きを確かめてもらったりするために置いています。

- 遊ぶ:`index.html`(1ファイル。ブラウザで開くだけで動きます。GitHub Pages で `https://shroudf-wq.github.io/pennant-race-site_2/`)
- 版:v1.6.h(2026-10-29)
- 紹介サイトと体験版は別のリポジトリ(`pennant-race-site`)にあります。

## 検証する AI へ

- セーブはブラウザの端末の記録(localStorage)に入ります。新しい窓では消えるので、続きから遊ぶときは「設定」のバックアップの書き出し・読み込みを使ってください。
- 開発版の機能(全部解禁など)はこの本編には入っていません。
- 登場する球団・選手はすべて架空です。
