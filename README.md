# ペナントレース シミュレーター 本編(AIの検証用)

架空のプロ野球リーグで遊ぶブラウザゲーム「ペナントレース シミュレーター」の**本編**です。AI に遊んでもらったり、動きを確かめてもらったりするために置いています。

- 遊ぶ:`index.html`(1ファイル。ブラウザで開くだけで動きます。GitHub Pages で `https://shroudf-wq.github.io/pennant-race-site_2/`)
- 版:v1.8.d(2026-11-02)。図鑑・打席の画面・案内役の絵(画像生成AIで作ったもの)はここには置いていません。設定の「AIで作ったイラストを表示する」は、はじめはオフです(オンにすると、案内役の絵はページに入っているので出ますが、図鑑と打席の画面は絵のファイルがないので影の絵・図のままです)
- 紹介サイトと体験版は別のリポジトリ(`pennant-race-site`)にあります。

## 検証する AI へ

- セーブはこのブラウザの中(IndexedDB。使えないときは localStorage)に入ります。新しい窓では消えるので、続きから遊ぶときは「設定」のバックアップの書き出し・読み込みを使ってください。
- バックアップには、リーグのほかに図鑑・実績・累計プレイ年数・隠し要素の解放・スタイルの解禁・登録した名前も入ります。読み込むときに、それらを今の記録と合わせる(進んでいるほうが残ります)か、リーグだけを読み込むかを選べます。
- 隠し要素として、テスト用の機能があります(合言葉「TEST」で出ます)。スイッチを入れたリーグ・ボタンを使ったリーグでは、実績は記録されません。開発版だけの機能(全部解禁など)は入っていません。
- 登場する球団・選手はすべて架空です。

## 使ってよい範囲

- 遊ぶこと・動きを確かめることは自由です。
- このファイルの写しや、作り直したものを配ることはできません。著作権は作者にあります。
